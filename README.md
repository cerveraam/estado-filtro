# Estado del filtro

Página que abre el QR de la tira de cada Montana: muestra cuándo toca cambiar el cartucho.

- `index.html?s=10LW12-033-001` muestra el estado de esa referencia.
- `data.json` solo guarda referencia, fecha de registro y fecha del último cambio. Sin nombres, emails ni datos de clientes.
- Lo actualiza cada día la revisión del programa instalador.
